# CSU — калькулятор и конвертер единиц

Консольное приложение на Python для вычисления арифметических выражений и перевода величин между единицами измерения. Каждая команда выполняет одну операцию, выводит результат и сохраняет успешное вычисление в JSON-файл.

## Возможности

- Сложение, вычитание, умножение и деление с учётом приоритета операций.
- Целые и дробные числа, унарные знаки `+` и `-`, пробелы между числами и операторами.
- Конвертация длины, массы и температуры.
- Проверка ввода, деления на ноль, переполнения и температуры ниже абсолютного нуля.
- История успешных операций в `successful_data.json`.
- Справка для приложения каждой команды через `--help`.

## Установка и запуск

Склонируйте репозиторий:

```sh
git clone https://github.com/Chistiy-fun/CSU.git
cd CSU
```

### Вариант 1: через uv

Из корня проекта установите зависимости, затем перейдите в `src`:

```sh
uv sync --frozen
cd src
```

```sh
uv run python -m toolkit calc "2 + 3 * 4"
uv run python -m toolkit convert 1.5 --from kg --to g
uv run python -m toolkit --help
```

### Вариант 2: через venv

```sh
python3 -m venv .venv
source .venv/bin/activate
cd src
python -m toolkit calc "2 + 3 * 4"
```

## Калькулятор

```sh
python -m toolkit calc "выражение"
```

Передавайте выражение в кавычках, чтобы терминал воспринимал его как один аргумент.

| Команда | Результат |
| --- | --- |
| `python -m toolkit calc "2 + 3 * 4"` | `14.0` |
| `python -m toolkit calc "20 - 12 / 3 * 2 + 1"` | `13.0` |
| `python -m toolkit calc "8 / 4 / 2"` | `1.0` |
| `python -m toolkit calc "-2 * -3"` | `6.0` |
| `python -m toolkit calc "2--3"` | `5.0` |
| `python -m toolkit calc "2.5 * 4 + .5"` | `10.5` |

Умножение и деление выполняются раньше сложения и вычитания. Операции одного приоритета выполняются слева направо.

Десятичный разделитель — точка: `1.5`, `.5`, `5.`. Знаки перед числом допустимы и после оператора, например `2 * -3`. Пробелы пропускаются, но не объединяют числа: `12 34` считается ошибкой.

**Ограничения:** скобки, степени, остаток от деления, функции, переменные и экспоненциальная запись (`1e3`) в калькуляторе не поддерживаются. Вычисления выполняются с типом `float`, поэтому возможны погрешности: например, `0.1 + 0.2` может дать `0.30000000000000004`.

## Конвертер

```sh
python -m toolkit convert ЧИСЛО --from ЕДИНИЦА --to ЕДИНИЦА
```

Оба параметра, `--from` и `--to`, обязательны. Перевод возможен только внутри одной группы.

| Группа | Поддерживаемые обозначения |
| --- | --- |
| Длина | `mm` — миллиметры, `cm` — сантиметры, `m` — метры, `km` — километры |
| Масса | `g` — граммы, `kg` — килограммы |
| Температура | `c` — градусы Цельсия, `f` — градусы Фаренгейта, `k` — кельвины |

Обозначения вводятся латиницей без символа `°`. Регистр не важен: `KM` и `km` равнозначны.

| Команда | Результат |
| --- | --- |
| `python -m toolkit convert 1 --from km --to m` | `1000.0` |
| `python -m toolkit convert 25 --from cm --to mm` | `250.0` |
| `python -m toolkit convert 1.5 --from kg --to g` | `1500.0` |
| `python -m toolkit convert 500 --from g --to kg` | `0.5` |
| `python -m toolkit convert 0 --from c --to f` | `32.0` |
| `python -m toolkit convert 0 --from c --to k` | `273.15` |
| `python -m toolkit convert -40 --from c --to f` | `-40.0` |

Конвертер принимает одно число, а не выражение. Для дробей используйте точку. Значения `nan` и `inf` запрещены. Температура не может быть ниже `−273.15 °C`, `−459.67 °F` или `0 K`. Отрицательные значения длины и массы текущая реализация допускает.

## История операций

После успешной команды приложение дописывает запись в массив в файле `successful_data.json` **в текущей рабочей папке**. При запуске по инструкции это `src/successful_data.json`. Если файла нет, он создаётся; если он уже существует, прежние записи сохраняются.

Пример новых записей:

```json
[
    {
        "argument": "calc",
        "expression": "2 + 3 * 4",
        "result": 14.0
    },
    {
        "argument": "convert",
        "expression": "convert 1.5 --from kg --to g",
        "result": 1500.0
    }
]
```

Неудачные вычисления и вызовы справки в историю не добавляются. Команд просмотра и очистки истории нет: файл можно открыть текстовым редактором, а для сброса заменить его содержимое на `[]` или удалить файл.

## Как это работает

1. `__main__.py` вызывает `main()`; `argparse` разбирает команду `calc` или `convert` и её аргументы.
2. Для `calc` модуль `tokenization.py` разбивает строку на числа и операторы, а `validation.py` проверяет их порядок и обрабатывает унарные знаки. `calculator.py` вычисляет произведения и частные внутри слагаемых, затем складывает слагаемые.
3. Для `convert` значение преобразуется в `float`, обозначения приводятся к нижнему регистру и проверяется совместимость единиц. Длина и масса пересчитываются по формуле `значение × коэффициент_исходной / коэффициент_целевой`; коэффициенты заданы относительно метра и килограмма. Температура переводится через шкалу Цельсия.
4. Результат выводится в терминал и записывается в историю. Ошибки вычисления и конвертации передаются через `ToolkitErrors` и выводятся с префиксом `Ошибка:`.

## Справка и ошибки

```sh
python -m toolkit --help
python -m toolkit calc --help
python -m toolkit convert --help
```

Например, команда `python -m toolkit calc "1 / 0"` выведет:

```text
Ошибка: Деление на ноль
```

Приложение также сообщает о пустом выражении, недопустимых символах, пропущенных операндах, неверных числах, неизвестных или несовместимых единицах и слишком большом результате. Неверные аргументы командной строки обрабатывает `argparse`.

При штатном выполнении результат попадает в `stdout`, код завершения — `0`. Обрабатываемые ошибки ввода и вычислений выводятся в `stderr`, код завершения — `2`. Справка возвращает код `0`.

## Тестирование

Тесты проверяют приоритет операций, унарные знаки, дробные числа, конвертацию, температурные границы, некорректный ввод, справку, вывод CLI и коды завершения.

Запускайте тесты **из корня проекта**. Если находитесь в `src`, сначала выполните `cd ..`. Укажите `src` в `PYTHONPATH`, чтобы пакет был доступен и тестам, и запускаемым ими дочерним процессам.

**macOS / Linux:**

```sh
PYTHONPATH=src uv run pytest -q
```

**Windows PowerShell:**

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) "src")
uv run pytest -q
```

При использовании `venv` установите `pytest` командой `python -m pip install "pytest>=8.4.2"`, затем замените `uv run pytest -q` на `python -m pytest -q`, сохранив настройку `PYTHONPATH`.

CLI-тесты записывают успешные операции в `successful_data.json` текущей папки. При запуске из корня проекта они изменят корневой файл истории.

## Проверки при разработке

После `uv sync --frozen` можно подключить проверки перед коммитом и запустить их вручную из корня проекта:

```sh
uv run pre-commit install
uv run pre-commit run --all-files
```

Без `uv` сначала установите инструмент в активированное окружение: `python -m pip install pre-commit`, затем выполняйте команды `pre-commit install` и `pre-commit run --all-files`.

Конфигурация включает mypy, Ruff, проверку JSON/YAML/TOML, пробелов в конце строк, завершающего перевода строки и размера добавляемых файлов.
